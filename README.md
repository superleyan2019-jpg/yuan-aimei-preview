# 元艾美牙醫診所｜主管審稿預覽

這是元艾美牙醫目前設計版本的獨立預覽站，使用 GitHub Pages 發布。原本正式網站、網域與主機設定均不屬於此專案。

## 頁面

- 首頁：index.html
- 人工植牙：implant.html
- All-on-4：all-on-4.html
- 牙齒矯正與隱形矯正：orthodontics.html
- 全瓷美學：ceramic-dsd.html
- 顯微根管：microscopic-endodontics.html
- 醫療團隊：team.html

## 審稿範圍與目前狀態

- 本次提供既有版面的桌機、平板及手機預覽，供設計與內容確認。
- Google 評論目前為明確標示的版型示意，尚未串接真實評論。
- 地圖使用已製作的 Google 地圖截圖，點擊可開啟位置與導航。
- 預約按鈕連至已提供的 LINE；首頁電話、Facebook 與地圖維持原本設定。
- 醫療團隊已提供七位醫師介紹，真人照片仍為清楚標註的佔位示意；牙科知識文章內頁尚未製作。
- 頁面包含 noindex,nofollow；這是公開預覽網址，並非存取權限或密碼保護。

## 發布方式

由 main 分支根目錄發布 GitHub Pages，不設定 CNAME 或正式網域。後續修改推送至本專案後，沿用同一個預覽網址。
